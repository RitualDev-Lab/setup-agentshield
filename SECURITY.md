# Security Policy & Vulnerability Disclosure

RitualDev Lab takes the security of the **setup-agentshield** GitHub Action seriously.

## Supported Versions

| Version | Supported | Response Target |
| :--- | :---: | :---: |
| **v1 / >= 0.2.2** | Active | Critical & High: < 24 Hours |

## Reporting a Vulnerability

Please **do not** open public GitHub issues for undisclosed GitHub Actions supply-chain or workflow vulnerabilities.

- **GitHub Private Security Advisory (Preferred)**: [Report a Security Advisory](https://github.com/RitualDev-Lab/setup-agentshield/security/advisories/new)
- **Email**: `security@ritualdev.in` with subject `[SECURITY VULNERABILITY] setup-agentshield`

## Compliance & Control Alignment

- **Status**: SOC 2 Type II & ISO 27001 Control-Mapped Architecture (**Self-Attested Readiness; Formal Independent Audit Planned**).
- **Trust & Control Mapping Portal**: [https://ritualdev.in/trust](https://ritualdev.in/trust)
